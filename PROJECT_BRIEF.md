# TranscreveJá / Ouviescrevi - Brief do Projeto

## Objetivo
Reativar o projeto depois de vários meses parado.

## O que quero
Quero transformar este projeto numa plataforma simples para:
- transcrever áudio/vídeo;
- resumir textos, PDFs e transcrições;
- traduzir conteúdos;
- gerar emails;
- gerar perguntas de estudo;
- exportar resultados em PDF, DOCX, TXT, JSON e SRT.

## Prioridade atual
Antes de criar novas funcionalidades, quero:
1. Perceber se o projeto ainda funciona.
2. Saber como correr o backend localmente.
3. Saber como correr o frontend localmente.
4. Identificar dependências desatualizadas.
5. Encontrar erros ou problemas de segurança.
6. Criar uma lista de melhorias prioritárias.

## Regras
- Não alterar código sem explicar primeiro.
- Criar sempre alterações em pequenos passos.
- Evitar refatorações grandes sem necessidade.
- Priorizar estabilidade, segurança e relançamento rápido.
- Não mexer em produção.
